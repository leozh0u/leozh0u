# Hi, I'm Leo

CS at Rice, originally from Auckland. I work on backend and infrastructure, mostly in Go and Python. Most of my time goes to [blundernet](https://github.com/leozh0u/blundernet), a Go service fleet that puts a chess engine I trained online: game state in Redis, inference on queue-fed workers so a slow move never blocks a request, the AWS stack in Terraform. The engine itself is [blundernet-engine](https://github.com/leozh0u/blundernet-engine), a small residual net with PUCT search written first in Python and then in C++ through pybind11, retrained on a schedule without me. It plays around 1000 Elo, which is bad at chess and about right for a network this size.

The rest of the shelf is older. [quant-signals](https://github.com/leozh0u/quant-signals) is a backtester that mostly proved my trading ideas stop working once I charge them transaction costs, and [stm32-bldc-motor-controller](https://github.com/leozh0u/stm32-bldc-motor-controller) is bare-metal firmware written against the reference manual, left over from starting in electrical engineering.
